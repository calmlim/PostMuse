Support

Troubleshooting for the local-first PostMuse Chrome extension.

Before reporting a problem

  • Confirm the selected Provider model exists and your own API key has access.
  • Approve the exact Provider origin when Chrome asks.
  • Check Provider balance, rate limits, and organization verification requirements.
  • Use Settings → Privacy & local data → Copy safe diagnostics.

Safe reports

Never include an API key, Authorization header, private draft, or generated image in a public report. Safe diagnostics intentionally contain status metadata only.

Contact

Search existing reports or create a new issue at github.com/calmlim/PostMuse/issues.
