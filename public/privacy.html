PostMuse · Privacy

Privacy policy

Effective August 11, 2026

PostMuse is a local-first, bring-your-own-key writing extension. PostMuse does not run a developer-operated backend, account system, analytics, advertising, or telemetry.

Data handled

PostMuse handles text you enter or upload, generated drafts, prompt templates, local history, Provider settings, and API keys. A development build may also handle the text of one visible X post only after you click its PostMuse control.

Storage and transfer

Settings, prompts, keys, and optional history stay in your Chrome profile. Image bytes are held only for the current preview/download session. When you click Generate, the necessary prompt and source content are sent directly over HTTPS to the AI Provider and origin you configured. Provider handling is governed by that Provider’s policies.

What the developer does not receive

The PostMuse developer does not receive, sell, use for advertising, or allow human access to your API keys, drafts, prompts, browsing activity, generated content, or local history. PostMuse does not use Google APIs to obtain user data.

Control and deletion

You can delete individual history entries, clear history, delete saved API keys, or reset all PostMuse local data from Settings. Uninstalling is also controlled by Chrome. Revoke leaked keys in the relevant Provider console.

Chrome Web Store Limited Use

PostMuse’s use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only for the user-facing writing features described here.

Support

See the support page or open an issue in the PostMuse repository.

隐私政策摘要

PostMuse 是本地优先、由用户自备 API Key 的写作扩展，没有开发者运营的后端、账号、分析、广告或遥测。设置、提示词、密钥和可选历史保存在你的 Chrome Profile 中。只有点击“生成”时，必要内容才会通过 HTTPS 直达你配置的 AI Provider，并受该 Provider 的政策约束。

开发者不会收到、出售或读取你的密钥、草稿、生成结果或历史。你可以在设置中删除密钥、清空历史或重置全部 PostMuse 本地数据。PostMuse 对 Chrome API 信息的使用遵守 Chrome Web Store User Data Policy（包括 Limited Use 要求）。
