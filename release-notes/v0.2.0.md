# PostMuse v0.2.0

PostMuse v0.2.0 expands the local-first X writing workflow with complete image creation, safer
long-form generation, more languages, and a more reliable inline and Side Panel experience.

## Highlights

- Create standalone images or companion images for a generated draft with OpenAI Images or Gemini Images.
- Choose image style, aspect ratio, 1K/2K output, optional image text, then preview and download locally.
- Generate posts, replies, quotes, threads, and Premium long posts with custom targets up to 25,000 characters.
- See an X-compatible weighted character count for CJK text, emoji, and URLs.
- Use PostMuse in ten interface languages and generate content in a broader set of output languages.

## What’s changed

### Added

- Standalone image creation and per-draft companion image creation.
- Configurable OpenAI Images and Gemini Images Provider settings with separate BYOK credentials.
- Optional writing profile, creation defaults, custom length targets, and X weighted counts.

### Improved

- Refined X inline and Side Panel layouts, defaults, navigation behavior, regeneration, and history sync.
- Added live minimal Provider connection tests and safer API-key binding to Provider destinations.
- Added correct OpenAI image sizing, local crop/scale handling, and final pixel validation.
- Reduced oversized regeneration context and bounded local history storage.

### Fixed

- Fixed custom lengths above 280 and targeted regeneration through 25,000 characters.
- Fixed Anthropic/Gemini sampling compatibility and Provider-specific parameters.
- Fixed image aspect-ratio mismatches, copy feedback, cancellation, and several inline-panel interactions.

## Installation

1. Download `postmuse-0.2.0-chrome.zip` and `SHA256SUMS` below.
2. Optionally verify the archive with `shasum -a 256 -c SHA256SUMS`.
3. Extract the ZIP to a permanent folder.
4. Open `chrome://extensions`, enable **Developer mode**, and choose **Load unpacked**.
5. Select the extracted folder containing `manifest.json`.
6. Open PostMuse, configure your own Provider API key, and run the live connection test.

## Upgrade notes

- Replace the files in the same extracted installation folder, then click **Reload** in `chrome://extensions`.
- Existing settings, prompt overrides, writing profile, API-key records, and compatible local history are retained.
- Provider destination changes may require re-entering the corresponding API key by design.

## Known limitations

- PostMuse is distributed for manual Chrome Developer mode installation and is not yet in the Chrome Web Store.
- PostMuse is BYOK. Provider requests can incur charges, including image generation and live connection tests.
- Publishing remains manual; PostMuse does not fill the X composer or publish automatically.
- The X inline panel uses a Content Script and is not authorized, affiliated with, or endorsed by X.
- Provider APIs and X policies can change; review the current terms before use.
